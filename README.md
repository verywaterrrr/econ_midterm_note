# ECON2103 Midterm Study Notes

A bilingual (English / Traditional Chinese) study site for Chapters 1–8, 14 and 15. Includes short lessons, diagrams, worked examples and browser-local retrieval practice. The `dist` directory is the complete static site and can be opened with any static web server. GitHub Pages deploys `dist` using the included workflow.

The lessons are unofficial summaries based on the learner's course materials. Instructor slide decks and problem-set PDFs are not included. Quiz progress is stored only in the current browser and does not establish mastery.

The current build script expects the original learner's local notes and bundled Markdown library; the generated HTML in `dist` is self-contained site source and can be edited directly.
